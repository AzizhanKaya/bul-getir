# Proje Yürütücüsü ve Ekip Organizasyon Şeması

Ekip tek kişiden oluştuğu için proje yürütücüsü beş rolün tamamını üstlenir.

```
                Azizhan Kaya
            Proje Yürütücüsü
                    │
   ┌──────────┬─────┴─────┬──────────────┬───────────────┐
   │          │           │              │               │
 Proje      Mobil       Veri ve        Test ve        Halkla
 Yönetimi   Geliştirme  Sunucu         Dokümantasyon  İlişkiler
```

| Rol | Sorumlu | Görevler |
| --- | --- | --- |
| Proje yönetimi | Azizhan Kaya | İş planı, haftalık ilerleme raporları, performans kaydı |
| Mobil geliştirme | Azizhan Kaya | Flutter ekranları, kamera, harita, bildirim entegrasyonu |
| Veri ve sunucu | Azizhan Kaya | SQLite şeması, Firebase kurulumu, eşitleme mantığı |
| Test ve dokümantasyon | Azizhan Kaya | Cihaz testleri, GitHub README, final raporu |
| Halkla ilişkiler | Azizhan Kaya | Proje sonunda LinkedIn tanıtım paylaşımı |

## Performans kayıt şablonu

Her hafta doldurulur, proje sonunda rapora eklenir. Haftalık kayıtlar [haftalık raporlarda](haftalik-raporlar/) tutulur.
